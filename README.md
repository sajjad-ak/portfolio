# Sajjad Akbar Khan - Portfolio Website

A modern, responsive portfolio website built to showcase my professional skills, experience, and projects.

## Features

- Responsive design that works on all devices
- Interactive UI with smooth scrolling and animations
- Project filtering functionality
- Contact form
- Modern and clean design

## Sections

- **Home**: Introduction and quick links
- **About**: Personal information and background
- **Skills**: Technical and soft skills
- **Experience**: Work history and education
- **Projects**: Portfolio of work with filtering options
- **Contact**: Contact form and information

## Technologies Used

- HTML5
- CSS3 (with custom variables and responsive design)
- JavaScript (vanilla JS for interactivity)
- Font Awesome (for icons)
- Google Fonts (Poppins)

## Setup and Customization

1. Replace placeholder content with your personal information
2. Add your own images to the `images` folder
3. Update links to your social media profiles and projects
4. Customize colors by modifying CSS variables in the `:root` selector

## Image Requirements

- Profile photo: Recommended size 500x500px
- Project thumbnails: Recommended size 600x400px
- All images should be optimized for web (compressed JPG or PNG)

## Deployment

This site can be deployed on any web hosting service that supports static websites, such as:
- GitHub Pages
- Netlify
- Vercel
- AWS S3
- Any traditional web hosting

## Customization Tips

- Change the color scheme by updating the CSS variables in the `:root` selector
- Add or remove sections as needed
- Customize the project categories to match your work
- Add additional pages if needed for detailed project descriptions
